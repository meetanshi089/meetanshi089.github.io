A cart that holds up with five apps listening

The theme, the bundle builder, a gift-with-purchase engine and several third-party apps all react to the same cart. Here's how I made it reliable.

The problem
Several apps wrapped fetch and listened for their own cart events. Shopify rate limits returned 429s, the drawer could show an empty cart, and competing listeners froze the page.
What I did
  • Fetch timeouts and retry on rate limits
  • Fresh drawer HTML via the Section Rendering API
  • One shared cart:updated event for every listener
  • Free gifts computed from the server-confirmed total
Result
The sitewide page freeze stopped. Bundle Buy Now goes straight to Shiprocket checkout, and Build Your Box free gifts reach checkout every time.
