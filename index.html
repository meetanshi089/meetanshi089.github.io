Process

How I ship a change

The same three steps for every fix, from a button colour to a new theme.

Compare with live production

Diff the file against the live theme first, so I fix the real difference, not a guess.

Build it as a section

Settings go in the schema, so the marketing team can change it later without me.

Verify at every breakpoint

Screenshots and measured styles at 390 and 1440px before I merge, then a written log entry.
